# Frontend — M6

Stack đề xuất: React + Vite (JavaScript), Bootstrap 5.
Node 22 bản vá >=22.12. Khóa dependencies trong package-lock.json.

M6 khởi tạo dự án Vite tại thư mục này (giữ README và cấu trúc đã có).
Dùng src/api cho giao tiếp API, src/components cho phần dùng lại,
src/pages cho các màn hình. Chưa có package.json hay ứng dụng chạy sẵn.

Màn hình cần dựng: danh sách/tìm kiếm job, form thêm/sửa, xác nhận xóa,
chuyển trạng thái, thống kê và minh họa function.
Đọc API base URL từ biến VITE_API_BASE_URL.
